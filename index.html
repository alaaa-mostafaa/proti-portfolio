RPA → APA

CI/CD Failure Diagnosis with Autonomous AI Agents

This thesis compares deterministic Robotic Process Automation (RPA) with Agentic Process Automation (APA) for CI failure diagnosis. Instead of static rules, our LangGraph-based agent uses Bayesian inference and a ChromaDB memory layer to autonomously gather evidence, analyze logs, and pinpoint errors.

// FINAL RESULTS //

The Agentic Process Automation (APA) approach outperformed traditional heuristics across all dimensions. By actively querying logs and code diffs, the agent accurately diagnosed complex CI failures. A retrieval-augmented memory acts as a safety net, correcting 40 diagnoses while regressing none.
